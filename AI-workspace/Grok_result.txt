Project: eCFR Analysis Website
Overview and Architecture
This project creates a simple web application to download, store, and analyze U.S. Federal Regulations from the eCFR (Electronic Code of Federal Regulations) API. The goal is to provide digestible insights for potential deregulation efforts, focusing on key metrics like word count per agency, historical changes over time, and checksums for each agency. I've added a custom metric: Amendment Frequency, which calculates the average number of amendments per section within an agency's regulations over the past year (using historical version data from the API). This helps inform decision-making by highlighting agencies with high regulatory churn, potentially indicating areas ripe for simplification or review.
High-Level Architecture

Data Downloader: A Java-based CLI tool or scheduled service that fetches current eCFR data via the public API. It retrieves agency mappings, title structures, and full XML content for each title, parses the XML to extract text, computes word counts and checksums (MD5 hash of content), and stores everything in PostgreSQL.
Database: PostgreSQL for server-side storage. Schema includes tables for agencies, titles, parts, sections (with content, metrics), and versions (for historical analysis).
Backend APIs: Java Spring Boot application exposing REST APIs to retrieve stored data and compute analyses. Deployed on Apache Tomcat as the web server.
Frontend UI: Simple HTML/JavaScript (with Bootstrap for styling) to display analyses in tables and charts. Users can select agencies, view metrics, and review raw results (e.g., section lists, historical timelines).
Deployment: Maven-based project for building. Tomcat hosts the WAR file. Data download can be run manually or via cron/scheduler.
Key Flows:
Download: Fetch agencies → Titles → Full XML per title → Parse and store sections with metrics.
Analysis: APIs query DB for current metrics; fetch historical versions from API on-the-fly for changes and amendment frequency.
UI: Interactive dashboard for metrics, with export to CSV for review.

Assumptions/Limitations: Focuses on current data storage; historical fetched dynamically to avoid massive storage. Handles ~50 titles and ~150 agencies. Error handling for API rate limits (none documented, but add retries). No authentication needed for API.

Custom Metric: Amendment Frequency

Definition: For an agency, count the total amendments (from versions endpoint) across its sections in the last 365 days, divide by number of sections.
Value: Identifies agencies with frequent updates, signaling complexity or instability for deregulation prioritization.

Technologies

Backend: Java 17, Spring Boot 3.x, Spring Data JPA, JAXB for XML parsing, Apache Commons for utilities.
Database: PostgreSQL 15+.
Web Server: Apache Tomcat 10.x.
Frontend: HTML5, JavaScript, Chart.js for visualizations, Bootstrap 5.
Build: Maven 3.x.
Other: SLF4J for logging, JUnit for tests.

    private static void downloadAgencies(Connection conn) throws Exception {
        String json = fetch(API_BASE + "admin/v1/agencies.json");
        JsonNode root = mapper.readTree(json);
        PreparedStatement ps = conn.prepareStatement("INSERT INTO agencies (name, cfr_references) VALUES (?, ?::jsonb)");
        Iterator<JsonNode> agencies = root.get("agencies").elements();
        while (agencies.hasNext()) {
            JsonNode agency = agencies.next();
            ps.setString(1, agency.get("name").asText());
            ps.setString(2, agency.get("cfr_references").toString());
            ps.executeUpdate();
        }
    }

    private static void downloadTitlesAndContent(Connection conn) throws Exception {
        String json = fetch(API_BASE + "versioner/v1/titles.json");
        JsonNode root = mapper.readTree(json);
        Iterator<JsonNode> titles = root.get("titles").elements();
        while (titles.hasNext()) {
            JsonNode title = titles.next();
            int titleNum = title.get("number").asInt();
            String currentDate = "2026-01-23";  // Use current date or from meta
            String xml = fetch(API_BASE + "versioner/v1/full/" + currentDate + "/title-" + titleNum + ".xml");

            // Parse XML (simplified; assume CFR XML schema bound to classes like Title, Part, Section)
            JAXBContext jaxb = JAXBContext.newInstance(Title.class);  // Define Title/Part/Section classes with @Xml annotations
            Unmarshaller unmarshaller = jaxb.createUnmarshaller();
            Title titleObj = (Title) unmarshaller.unmarshal(new StringReader(xml));

            // Insert title (map to agency via cfr_references query)
            PreparedStatement psTitle = conn.prepareStatement("INSERT INTO titles (number, name, latest_amended_on, agency_id) VALUES (?, ?, ?, (SELECT id FROM agencies WHERE cfr_references @> ?::jsonb))");
            psTitle.setInt(1, titleNum);
            psTitle.setString(2, title.get("name").asText());
            psTitle.setDate(3, java.sql.Date.valueOf(title.get("latest_amended_on").asText()));
            psTitle.setString(4, "[{\"title\":" + titleNum + "}]");  // Simplified matching
            psTitle.executeUpdate();
            int titleId = // Get last insert ID

            // For each part/section in titleObj
            for (Part part : titleObj.getParts()) {
                // Insert part
                PreparedStatement psPart = conn.prepareStatement("INSERT INTO parts (title_id, part_number, name) VALUES (?, ?, ?)");
                psPart.setInt(1, titleId);
                psPart.setString(2, part.getNumber());
                psPart.setString(3, part.getName());
                psPart.executeUpdate();
                int partId = // Get ID

                for (Section section : part.getSections()) {
                    String text = section.getContentText();  // Extract plain text from XML
                    int wordCount = text.split("\\s+").length;
                    String checksum = computeMD5(text);

                    PreparedStatement psSection = conn.prepareStatement("INSERT INTO sections (part_id, section_number, content_text, word_count, checksum, effective_date) VALUES (?, ?, ?, ?, ?, ?)");
                    psSection.setInt(1, partId);
                    psSection.setString(2, section.getNumber());
                    psSection.setString(3, text);
                    psSection.setInt(4, wordCount);
                    psSection.setString(5, checksum);
                    psSection.setDate(6, section.getEffectiveDate());  // From XML metadata
                    psSection.executeUpdate();
                }
            }
        }
    }

    private static String fetch(String url) throws Exception {
        try (CloseableHttpClient client = HttpClients.createDefault()) {
            HttpGet get = new HttpGet(url);
            try (CloseableHttpResponse response = client.execute(get)) {
                return EntityUtils.toString(response.getEntity());
            }
        }
    }

    private static String computeMD5(String input) throws Exception {
        MessageDigest md = MessageDigest.getInstance("MD5");
        byte[] digest = md.digest(input.getBytes());
        return new BigInteger(1, digest).toString(16).toUpperCase();
    }

Example fetch logic (add to downloader):Javaprivate static void downloadRecentFrDocuments(Connection conn, LocalDate fromDate) throws Exception {
    String base = "https://www.federalregister.gov/api/v1/documents.json";
    String params = "?conditions[publication_date][gte]=" + fromDate +
                    "&conditions[type]=RULE" +  // focus on final rules for amendments
                    "&per_page=1000" +  // max often 1000
                    "&order=oldest" +   // or newest; paginate
                    "&fields[]=document_number,title,type,agencies,publication_date,effective_date,html_url,pdf_url,cfr_references,abstract";

    int page = 1;
    while (true) {
        String url = base + params + "&page=" + page;
        String json = fetch(url);  // reuse your HTTP fetch method
        JsonNode root = mapper.readTree(json);
        JsonNode results = root.path("results");

        if (results.isEmpty()) break;

        for (JsonNode doc : results) {
            // Extract fields
            String docNum = doc.path("document_number").asText();
            String title = doc.path("title").asText();
            String type = doc.path("type").asText();
            String pubDateStr = doc.path("publication_date").asText();
            LocalDate pubDate = LocalDate.parse(pubDateStr);

            // Agencies: take first or primary
            JsonNode agencies = doc.path("agencies");
            Integer agencyId = null;
            if (!agencies.isEmpty()) {
                String agencyName = agencies.get(0).path("name").asText();
                // Query our DB to map name → id (fuzzy match if needed)
                PreparedStatement psAgency = conn.prepareStatement("SELECT id FROM agencies WHERE name ILIKE ?");
                psAgency.setString(1, "%" + agencyName + "%");
                ResultSet rs = psAgency.executeQuery();
                if (rs.next()) agencyId = rs.getInt("id");
            }

            // Insert
            PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO federal_register_documents (document_number, title, type, agency_id, publication_date, effective_date, html_url, pdf_url, cfr_references, abstract) " +
                "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?::jsonb, ?) " +
                "ON CONFLICT (document_number) DO NOTHING");
            ps.setString(1, docNum);
            ps.setString(2, title);
            ps.setString(3, type);
            ps.setObject(4, agencyId, java.sql.Types.INTEGER);
            ps.setDate(5, java.sql.Date.valueOf(pubDate));
            ps.setDate(6, doc.has("effective_date") ? java.sql.Date.valueOf(doc.path("effective_date").asText()) : null);
            ps.setString(7, doc.path("html_url").asText(null));
            ps.setString(8, doc.path("pdf_url").asText(null));
            ps.setString(9, doc.path("cfr_references").toString());
            ps.setString(10, doc.path("abstract").asText(null));
            ps.executeUpdate();
        }
        page++;
        Thread.sleep(1000);  // polite delay
    }
}

    @GetMapping("/agency/{agencyId}/amendment-frequency")
    public Map<String, Object> getAmendmentFrequency(@PathVariable Long agencyId,
                                                     @RequestParam(defaultValue = "365") int days) {
        LocalDate from = LocalDate.now().minusDays(days);

        // Count FR final rules linked to this agency in period
        Long ruleCount = jdbc.queryForObject(
            "SELECT COUNT(*) FROM federal_register_documents " +
            "WHERE agency_id = ? AND type = 'RULE' AND publication_date >= ?",
            Long.class, agencyId, Date.valueOf(from));

        // Sections count from eCFR storage
        Long sectionCount = jdbc.queryForObject(
            "SELECT COUNT(*) FROM sections s JOIN parts p ON s.part_id = p.id " +
            "JOIN titles t ON p.title_id = t.id JOIN agencies a ON t.agency_id = a.id " +
            "WHERE a.id = ?", Long.class, agencyId);

        double freq = sectionCount > 0 ? (double) ruleCount / sectionCount : 0.0;

private static void downloadRecentDockets(Connection conn, LocalDate fromDate) throws Exception {
    String endpoint = "/documents";
    Map<String, String> params = Map.of(
        "filter[postedDate][ge]", fromDate.toString(),
        "filter[documentType]", "Proposed Rule,Final Rule",  // focus on key types
        "sort", "postedDate",
        "page[size]", "250",
        "page[number]", "1"
    );

    int page = 1;
    while (true) {
        String url = API_BASE + endpoint + "?" + buildQueryString(params) + "&page[number]=" + page;
        String json = fetchWithHeader(url, "X-Api-Key", API_KEY);

        JsonNode root = mapper.readTree(json);
        JsonNode results = root.path("data");

        if (results.isEmpty()) break;

        for (JsonNode item : results) {
            String docketId = item.path("attributes").path("docketId").asText();
            String title = item.path("attributes").path("title").asText();
            String agencyAcronym = item.path("attributes").path("agencyAcronym").asText();
            // Map agencyAcronym → our agency_id (add mapping table or fuzzy match)
            Integer agencyId = lookupAgencyId(conn, agencyAcronym);

            PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO regulations_gov_dockets (docket_id, title, agency_id, document_type, posted_date, comment_start_date, comment_end_date, open_for_comment, json_data) " +
                "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?::jsonb) ON CONFLICT (docket_id) DO UPDATE SET ...");
            ps.setString(1, docketId);
            ps.setString(2, title);
            ps.setObject(3, agencyId, java.sql.Types.INTEGER);
            // Set other fields from attributes...
            ps.setString(9, item.toString());
            ps.executeUpdate();
        }
